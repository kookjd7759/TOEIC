## 수 일치  
1. 단수 주어 + 단수 동사  
    - A/An + 명사 - A student (is / are) waiting outside.
    - He/She/It - He (likes / like) coffee.
    - To 부정사 - To read books (are / is) enjoyable.
    - 동명사 - Watching movies (are / is) my hobby.
    > 주어에 to 부정사, 동명사가 들어가면 **단수 동사**로 취급
2. 복수 주어 + 복수 동사
    - 명사 + -s - My friends (enjoys / enjoy) playing soccer.
    - You/We/They - They (likes / like) Italian food.

## -s 붙이는 법칙
- 기본형 : + -s
- -sh/-ch/-x : + -es
- 자음 + y : y를 i로 바꾸고 + -es
- 모음 + y : + -s

## 수동태와 능동태  
- 수동태의 형태 = be동사/be동사 being/have been + p.p  

## 동사의 3단 변화  
- 일반 규칙 : + -ed
- -e로 끝나면 : + -d
- 자음 + y : y를 i로 바꾸고 + -ed
- 모음 + y : + -ed
- 단모음 + 단자음 : 자음을 한 번 더 쓰고 + -ed
- 불규칙
    - A-A-A : cut-cut-cut, put-put-put
    - A-B-A : come-came-come, run-ran-run
    - A-B-B : hold-held-held, keep-kept-kept
    - A-B-C : begin-began-begun, write-wrote-written

## 시제  
- 현재시제 단서 : usually (보통), always (항상), sometimes (가끔), often (종종)
    - He usually (eats / ate) breakfast at 7 A.M.
    - I always (arrives / arrive) at the office on time.
- 과거시제 단서 : yesterday (어제), ago (전에), last week/month (지난 주/달)
    - Mr.Kim (attends / attended) the client meeting yesterday.
    - SG Electronics (launched / launched) a new blender two weeks ago.
- 미래시제 단서 : tomorrow (내일), soon (곧), shortly (곧)
    - MS.Park (joined / well join) the video conference shortly.
    - The city officials (attend / will attend) the meeting tomorrow.
- 현재완료시제 단서 : since + 과거시점 (~이래로), for + 기간 (~동안)
    - MS.Johnson (has managed / have managed) the accounting team since last summer.
    - Hamilton Consulting (provided / has provided) legal services for two decades.
