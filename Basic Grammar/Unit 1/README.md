## 8품사 종류  
- 명사 : 사람/사물의 **이름**
- 대명사 : **명사를 대신**하는 말
- 동사 : '~하다/~이다' 사람이나 사물의 **동작과 상태**
- 형용사 : '~한' **상태나 성질**을 형용 (명사를 수식)
- 부사 : 동사/형용사/문장 전체/다른 부사를 **수식**
- 전치사 : **명사 앞**에 위치
- 접속사 : 단어, 구, 절 등을 **연결**
- 감탄사 : 감정 표현

## 문장 성분  
- 주어 (은/는/이/가/도) : 명사, 대명사
- 서술어 (~하다/이다) : 동사
- 목적어 (~을/를) : 명사, 대명사
- 보어 (~한/하게) : 명사, 대명사, 형용사
- 수식어 : 부사, 전치사구

## 1~5형식 필수 동사
- 1형식 : 주어 + 동사
    - ⭐ 1형식 동사 암기 - go, come, arrive, depart, work, rise
- 2형식 : 주어 + 동사 + 주격보어
    - ⭐ 2형식 동사 암기 - be동사, become, remain, stay
- 3형식 : 주어 + 동사 + 목적어
    - ⭐ 3형식 동사 암기 - 1, 2, 4, 5형식 동사가 아니고 '-을/를'의 해석이 자연스러우면 대부분 타동사
- 4형식 : 주어 + 동사 + 간접목적어 + 직접목적어 ((간목)에게 (직목)을/를)
    - ⭐ 4형식 동사 암기 - lend, send, teach, show, give, bring
- 5형식 : 주어 + 동사 + 목적어 + 목적격보어
    - ⭐ 5형식 동사 암기 - keep, find, consider, make
