# TOEIC  
이 저장소는 TOEIC 학습을 체계적으로 정리하기 위해 만든 학습 레포지토리입니다.  
영어 기초가 부족한 사람도 순서대로 따라오며 실력을 쌓을 수 있도록, **기초 문법**, **기초 어휘**, **문장 구조**, **Part별 핵심 개념**, **문제 풀이 방식**, **오답 정리**를 단계적으로 정리하는 것을 목표로 합니다.  

단순히 문제만 많이 푸는 방식이 아니라, 영어의 기본기를 먼저 다지고 그 위에 TOEIC 유형과 전략을 쌓아 올리는 흐름으로 학습 내용을 구성합니다.  
최종적으로는 초보자도 이 레포를 따라가며 TOEIC 점수를 만들 수 있는 학습 아카이브를 지향합니다.

## 시험 구성
TOEIC은 총 200문제, 990점 만점의 시험으로, LC와 RC의 두 영역으로 구성됩니다. 각 영역은 다음과 같은 Part로 세분화됩니다.
```markdown
TOEIC
├─ 1. Listening Comprehension (LC) | 100문제
│  ├─ Part 1 (사진 묘사) | 6문제
│  ├─ Part 2 (질의응답) | 25문제
│  ├─ Part 3 (대화) | 39문제
│  └─ Part 4 (담화/설명문) | 30문제
└─ 2. Reading Comprehension (RC) | 100문제
   ├─ Part 5 (단문 빈칸 완성: 어휘, 문법) | 30문제
   ├─ Part 6 (장문 빈칸 완성: 어휘, 문법, 문장) | 16문제
   └─ Part 7 (독해)
      ├─ Single Passage (단일 지문) | 29문제
      └─ Multiple Passage (복수 지문) | 25문제
```
